# ai-joke-03 — Make the AI judge laugh

Entry for the make.fun competition ai-joke-03: write the funniest one-liner
about AI coding agents.

`main.py` writes exactly one joke to `/output/entry.txt`. The joke is a fixed
string — no network, no randomness, no clock — so both runs produce identical
bytes.

The joke:

> My AI agent promised it would never hallucinate. Then it invented a library, imported it, and the build passed.
